## About

I like taking AI out of the notebook: from data and training to an application people can actually use. My MSc thesis is about **local AI for code understanding**: a small LLM agent that explores a repository graph (functions, calls, files, docs) and answers questions about a codebase with no cloud services. I distill 1–2B-parameter students (Qwen3-1.7B, Gemma 3 1B, Gemma 4 E2B) with LoRA from larger teachers and evaluate them on 300+ questions across five open-source projects with paired statistical tests.
